---
title: 'Core concepts'
description: 'Key terminology and concepts used throughout Spark'
---

## Organization

A team workspace that contains members and productions. Each organization has its own set of roles and permissions. You can belong to multiple organizations.

## Production

A project container within an organization — typically one per film, episode, or commercial. Productions hold scripts, scenes, and the Gallery.

## Script

A Fountain-format screenplay tied to a production. Scene headings in a script automatically generate scenes that you can build out in the scene editor.

## Scene

A 3D workspace generated from a script heading. Each scene has its own canvas, timeline, outliner, and properties panel where you arrange assets, set up lighting, and position cameras.

## Setup

A named arrangement of a scene — added, moved, or removed objects, plus any per-setup animation. Every scene starts with one automatic **Base** setup; add more (**Setup A**, **Setup B**, and so on) to cover the same scene from a different arrangement without disturbing the others. The setup you have active is where your edits land.

## Camera

A camera position, movement, and duration within a setup. A setup can hold several cameras. You can record camera moves in fly mode or set manual keyframes.

## Take

A recording made under a setup. Takes are numbered per setup, producing a slate like `24A-3` — scene 24, setup A, take 3 — or `24-3` for a take on the Base setup.

## Gallery

The production's review and planning view. Setups group their takes, an unshot setup still appears as a card, and each card can carry comments and annotations from the team.

## Scene file

An imported 3D asset used within a scene. Supported formats include USD, USDZ, PLY, and GLB.

## Locator

A named reference point in 3D space. Locators help align objects between the Spark web app and Jetset, and serve as anchors for positioning assets on set. See [locators in Blender](/create-usd/blender/scene-locators) for details on creating them in your 3D workflow.
