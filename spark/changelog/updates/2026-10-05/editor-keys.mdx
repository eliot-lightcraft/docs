---
title: "New keys for Split, Trim start, and Trim end"
description: "Split is now Ctrl+K, Trim start is Q, and Trim end is W"
---

Change · Web · Released [2026-10-05](/spark/changelog/changelog#2026-10-05)

Three Editor keys moved to make room for **Mark in** (**I**), **Mark out** (**O**), and **Overwrite** (**B**).

| Action | Key |
|---|---|
| Split the selected clip | **Ctrl+K** (**⌘K** on a Mac) |
| Trim the start of the selected clip to the playhead | **Q** |
| Trim the end of the selected clip to the playhead | **W** |

The tooltips on **Split**, **Trim start**, and **Trim end** show these keys while a clip is selected. **I**, **O**, and **B** no longer change a selected timeline clip.

**Up** and **Down** now step to the previous and next item in the left column, and the **Clip** pane follows.
