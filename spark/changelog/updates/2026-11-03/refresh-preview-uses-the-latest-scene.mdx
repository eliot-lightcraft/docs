---
title: "Refresh preview uses the latest scene"
description: "Refresh preview on a CG Take renders the scene as it is now, even in a tab that has been open a long time"
---

Fix · Web · Released [2026-11-03](/spark/changelog/changelog#2026-11-03)

**Refresh preview** on a CG Take now renders the 3D scene as it is now. Before, in a tab that had been open for a long time, it could render an older version of the scene until you reloaded the page.
