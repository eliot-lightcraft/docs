The scene library holds 3D scenes that are shared with every Spark user. You can import one and get your own copy of it, with its setups, cameras, and objects, to change as you like.

## Importing a library scene into a script

1. Open a script page.
2. In the 3D scenes panel, click **Import from library**, beside **Create a new 3D scene**.
3. The **Scene Library** window opens. The first card is **Empty scene**, which makes a new empty 3D scene. The other cards are the library scenes.
4. Click a library scene.

While Spark copies it, the window reads **Copying the scene and its files**, with the size of the files. When the copy is done, the message **Imported** appears with the scene's name.

To keep working while it copies, click **Continue in background**. The copy keeps going in the bottom bar, and you get a link to the scene when it is done.

## Starting an empty production from a library scene

A production with no script offers **Start from a library scene**, beside **Upload a script** and **Use default script**. Click it and pick a scene. Spark makes a new script to hold the copy, and opens the copied 3D scene when it is ready.

In a production that already has scripts, **Add a Script** lists **Start from a library scene** too, under **Upload**, **Use default script**, and **Skip to 3D scene**.

## Your copy is your own

The copy is a new 3D scene in your production, and its files count toward your organization's storage. Changes you make to it do not change the library scene, and later changes to the library scene do not reach your copy.
