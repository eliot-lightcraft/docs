---
title: "Use default script opens in Edit"
description: "A new script made with Use default script now opens in Edit with the element palette open"
---

Fix · Web · Released [2026-11-03](/spark/changelog/changelog#2026-11-03)

**Use default script** now opens the new script in Edit, with the element palette open, so you can start writing at once. Before, it opened in View. A reload of the page opens the script in View, as any other visit does.
