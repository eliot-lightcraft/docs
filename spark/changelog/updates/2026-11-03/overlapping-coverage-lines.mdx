---
title: "Each camera gets its own coverage line"
description: "Cameras that cover the same script lines no longer merge into one bar beside the script"
---

Fix · Web · Released [2026-11-03](/spark/changelog/changelog#2026-11-03)

In the 3D scene's **Script** tab, the coverage beside the script text now draws one thin line for each camera. Before, cameras that covered the same script lines merged into one bar. Point at a line to see the camera's name and tint the script lines it covers, and click the line to select the camera.

The orange line, which marks the camera at the playhead, now shows only while no camera is selected.
