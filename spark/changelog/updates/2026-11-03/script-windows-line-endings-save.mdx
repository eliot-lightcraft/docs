title: "Scripts with Windows line endings save"
description: "A script uploaded from a file saved on Windows now saves when you edit it"

Fix · Web · Released [2026-11-03](/spark/changelog/changelog#2026-11-03)

A script uploaded from a text file saved on Windows now saves normally when you edit it, and reaches **Saved**. Before, edits to such a script were never saved.
