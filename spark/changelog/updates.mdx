<Update label="2026-09-30" tags={["Web"]}>

### Features

- Use a modelled USD set as your location
- Cut straight from your Gallery lists in the Editor
- Choose production access when you invite people
- See keyboard shortcuts in tooltips
- Regenerate a take's BG
- Download Gallery takes as one zip
- Play and download takes on a shared list
- See setups, cameras and takes on scene cards
- Hide objects per setup

### Changes

- Shots are now called cameras and CG Takes
- The base setup is now labeled **Base Setup**
- The help button in the top bar is now a question mark
- The web app now points you to the Spark iOS app
- The **Watch tutorial** button is gone from an empty organization

### Fixes

- The Outliner no longer takes keyboard input after you click a row

</Update>
