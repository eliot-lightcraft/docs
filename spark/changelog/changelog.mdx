Each release lists what is new or different in Spark on the web: the things you can see and click. Click a title to open its update, which has the description and pictures. Every update in a release, including small fixes, is listed under **Updates** in the left menu.

New releases ship continuously, so this page updates as features go live.
Each entry is linkable, and the page has an RSS feed if you would rather
subscribe.

Release notes for the iPhone and iPad app are in the App Store, under the
app's version history.
