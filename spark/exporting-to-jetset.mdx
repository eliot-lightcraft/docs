## Workflow overview

The Spark-to-Jetset workflow bridges pre-production and production. Scenes designed in the Spark web app can be exported and loaded directly onto an iPhone or iPad running Jetset, bringing your planned shots to the physical set.

## USDZ export

Export a setup as a USDZ file to package all 3D assets, materials, and scene data — resolved for that setup's arrangement — into a single file that Jetset can load. The export process generates an optimized file sized for mobile performance.

## QR codes

After exporting, the Spark web app generates a QR code for the scene. Scan the QR code with Jetset on your iPhone or iPad to load the scene directly — no manual file transfer required.

## What transfers to Jetset

The following elements carry over from the Spark web app to Jetset:

- 3D assets and materials
- Camera positions and setup arrangements
- Locators and reference points
- Scene hierarchy and object relationships

## Jetset vs the Spark iOS app

Use the **Spark iOS app** for previs, live blocking, and iPhone/iPad production that does not need a cinema camera. Use **Jetset** when a cinema camera is on set:

| Capability | Spark iOS app | Jetset |
|------------|-----------------|--------|
| AI matting (no green screen) | Yes | Yes |
| Green-screen or blue-screen keying | Yes | Yes |
| Cinema camera coupling (e.g., RED) | No | Yes |
| Photogrammetry | No | Yes |
| Tracking data export | Yes | Yes |
